RSVP lookup has been changed to use Family/Last Name + First Name.

Important:
Replace your Apps Script Code.gs with the included Code.gs file, then save and redeploy your Web App.

The spreadsheet headers are now:
Submitted At, Family Name, First Name, Household Lookup Key, Attendance, Guest Count,
Rehearsal Dinner, Morning-After Brunch, Guest Number, Guest Name, Adult or Child,
Meal Selection, Dietary Restrictions / Other Comments.

Lookup behavior:
- Guests enter family/last name and first name.
- The site looks up those two fields together.
- If a match is found, it displays everyone who RSVP'd together and allows edits.
- If no match is found, guests can start a new RSVP.
